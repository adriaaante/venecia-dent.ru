# Стоматология «Венеция» — venecia-dent.ru

Сайт семейной стоматологии «Венеция» (Московская область, г. Мытищи,
ул. Мира, д. 37). Плоская статика: HTML + CSS + ванильный JS, без сборщика.

- Фирменный стиль и палитра — `BRAND.md`
- Заметки для агента/разработчика — `CLAUDE.md`
- Деплой на reg.ru — `scripts/deploy.sh` (запускается на сервере)
- Форма заявок: `assets/js/main.js` → `api/lead.php` → Telegram
  (токен — в `api/config.php`, создаётся на сервере из `api/config.php.example`)
